## Обзор

| Папка | Описание |
|-------|----------|
| [server/](server/README.md) | Intan TCP/UDP сервер — запускается на плате |
| [gui/](gui/README.md) | GUI‑клиент — управление с ПК |
| [scripts/](scripts/README.md) | Shell‑скрипты запуска и просмотра логов |
| [autostart/](autostart/README.md) | Установка автозапуска через systemd |
| [deploy/](deploy/README.md) | Конфигурация systemd для развёртывания |

---

## Компоненты

| Компонент | Путь | Описание |
|-----------|------|----------|
| **Intan TCP/UDP сервер** | `server/` | TCP для стимуляции, UDP для регистрации. [Подробнее →](server/README.md) |
| **GUI‑клиент (Python)** | `gui/` | Tkinter: стимуляция, паттерны, регистрация, графики. [Подробнее →](gui/README.md) |
| **Скрипты** | `scripts/` | Запуск с логами, просмотр логов. [Подробнее →](scripts/README.md) |
| **Автозапуск** | `autostart/` | Установка systemd‑сервиса. [Подробнее →](autostart/README.md) |
| **Deploy** | `deploy/` | unit‑файл systemd. [Подробнее →](deploy/README.md) |

## Связь компонентов

```
┌─────────────────────┐     TCP:9000      ┌─────────────────────────────────────┐
│  ПК                 │ ───────────────►  │  Orange Pi Zero 2W                  │
│  GUI (gui/)         │                   │  intan_server (server/)             │
│                     │ ◄───────────────  │  ├── TCP: управление стимуляцией    │
│                     │     UDP:9001      │  └── UDP: поток ADC                 │
└─────────────────────┘                   └─────────────────────────────────────┘
```

Подробнее см. README в каждой подпапке.
