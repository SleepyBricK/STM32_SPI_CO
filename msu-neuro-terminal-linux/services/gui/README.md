# GUI‑клиент Intan RHS2116

Графический клиент для управления стимуляцией Intan RHS2116 через TCP. Запускается на ПК (Windows / Linux / macOS) и подключается к TCP‑серверу на плате.

|------|------------|
| `intan_gui_clientv5_linux.py` | Основной скрипт GUI |

## Зависимости

**Обязательно:**

- Python 3.x
- `tkinter` (обычно входит в Python)
- `numpy`

**Опционально (для графиков):**

```bash
pip install matplotlib
```

Без matplotlib графики недоступны, но управление стимуляцией работает.

## Запуск

**Через терминал:**
```bash
python3 intan_gui_clientv5_linux.py
```

**Без терминала (удобный способ):**

1. Один раз выполните установку ярлыка:
   ```bash
   bash install_desktop_launcher.sh
   ```
   (или `./install_desktop_launcher.sh` после `chmod +x install_desktop_launcher.sh`)

2. После этого GUI можно запускать:
   - **Linux:** двойным щелчком по ярлыку на рабочем столе или из меню приложений (категория «Наука»)
   - **macOS:** двойным щелчком по `Intan RHS2116 Control.command` на рабочем столе (в Finder)
   - двойным щелчком по `launch_intan_gui.sh` в файловом менеджере

---

## Подключение к серверу

1. Узнайте IP платы (Orange Pi Zero 2W) в локальной сети.
2. В GUI введите:
   - **Хост:** IP платы (например, `192.168.1.100`)
   - **Порт:** 9000 (TCP по умолчанию)
3. Нажмите «Подключиться».

---

## Функции

- Подключение к TCP‑серверу на плате
- Управление стимуляцией (импульсы, пилообразный сигнал и др.)
- Просмотр EMG/ADC данных
- Графики (при установленном matplotlib)
- Сохранение данных в CSV

## Переменные окружения (EMG)

| Переменная | По умолчанию | Описание |
|------------|--------------|----------|
| `EMG_CH_A` | 0 | Канал A для дифференциального EMG |
| `EMG_CH_B` | 2 | Канал B для дифференциального EMG |
| `EMG_USE_DIFFERENTIAL` | true | Использовать дифференциальный режим |
